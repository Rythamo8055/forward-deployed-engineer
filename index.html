📌 What is an FDE?

Coined by Palantir (ex-Deltas). Military analogy: deployed forward, close to action.

  • Embed: on-site ~25-50%, map domain & processes
  • Build: production code in customer infra — RAG, fine-tune, evals, data wiring
  • Feed back: customer fix → core product (ex: OpenAI + John Deere → Realtime API)

Examples: John Deere + OpenAI (Iowa), Ramp pods, Matta factory floor, AWS NFL Fantasy AI / NFL IQ, NBA, Cox Auto, Southwest.

🔥 Why hottest job 2026?

  • 95% enterprise AI pilots fail (MIT 2025) — siloed data
  • a16z: enterprises = “grandma getting an iPhone” — need setup
  • >50% tech postings need AI/ML, 84% orgs ↑ AI spend
  • “FDEs, not FTEs” — Andela

FDE vs others

Solutions Eng: advisory PoC, rarely prod code • AI Eng: builds AI, not embedded • FDE: embedded + prod code + back to core product
